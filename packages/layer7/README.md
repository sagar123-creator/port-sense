# Layer 7 — Time engine

Calendar + simulated live replay from **verified 2023 JNPA events** and **Open-Meteo historical temperature**.

- Change the date → **temperature changes** (real 2023/2024 archive).
- JNPT 2023 dwell = real daily event p90 (mean shown separately).
- Live page posts a new sample every **10 minutes** (deterministic replay, not AIS).
- **IPA Daily Vessels Position**: snapshot days IPA actually published (July + August 2026). Not every calendar day. Not AIS, not dwell hours, not rupees. Remarks kept when the PDF extract has them.
